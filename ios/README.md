# StellrGlass XE1 for iPhone

SwiftUI app (iOS 17+, iPhone, portrait) that Glass dials into. It runs the TCP server on port
9090 (PROTOCOL.md) and turns iPhone features into protocol messages: pairing, cards, Apple Maps
directions, GPS, Photos, screencast and Wi-Fi setup.

## Build

```
brew install xcodegen
cd ios && xcodegen && open GlassBridge.xcodeproj
```

Select the GlassBridge target › Signing & Capabilities › Team, then run on the iPhone. A free
Apple ID works but the install expires after 7 days. `GlassBridge.xcodeproj` and
`GlassBridge/Info.plist` are generated by XcodeGen: don't edit or commit them.

Command-line check: `xcodegen && xcodebuild -scheme GlassBridge -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build`

Compiled with Xcode 27.2 on the iOS 27.2 SDK with no errors or warnings (November 2026).

## First run

iOS asks for Local Network (needed, or Glass can never connect), Location (When In Use) and
Photos (add only, while Save photos is on). With nothing paired, pairing opens for 2 minutes on
launch. The Glass tab shows the server state ("Listening on port 9090"), pairing state and
Glass status. Tools › Setup guide walks through the whole Glass side; Tools › Event log shows
what happened.

## Testing without Glass

From a laptop on the iPhone's Personal Hotspot (the iPhone is usually `172.20.10.1`):

```
python3 tools/fake_glass.py 172.20.10.1                       # pairs while the window is open
python3 tools/fake_glass.py 172.20.10.1 --upload IMG.jpg      # lands in Photos
python3 tools/fake_glass.py 172.20.10.1 --frame shot.jpg      # Media › Mirror Glass screen
```

## Layout

| Folder | Contents |
|---|---|
| `GlassBridge/Core/` | Protocol, pairing and nav logic. Foundation only; tested on Linux by `tools/swift-check`. |
| `GlassBridge/Link/` | `GlassServer` (NWListener, sessions, heartbeat), `GlassLink` (state, pairing, actions), `MediaReceiver` (uploads to Photos) |
| `GlassBridge/Services/` | `LocationService` (GPS and background keep-alive), `NavigationService` (MapKit search/routing driving `NavTracker`) |
| `GlassBridge/Intents/` | Shortcuts "Send to Glass" action and App Shortcuts |
| `GlassBridge/Views/` | Glass, Navigate, Media and Tools tabs, setup guide, event log |
| `GlassBridge/App/` | App entry point, `ContentView` (TabView), formatting helpers |
| `LinuxCheck/` | Not part of the app. `run.sh` type-checks every app file on Linux against stand-ins for the Apple frameworks and runs a simulation of the server, pairing and accept-time nav logic. It is not a substitute for Xcode. |

Settings live in `UserDefaults`: `pairToken`, `phoneName`, `syncEnabled`, `shareLocation`,
`stayAlive`, `savedMediaIDs`, and the Find my Glass time and place.
